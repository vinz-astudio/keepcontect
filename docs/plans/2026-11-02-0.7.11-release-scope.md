## Release order

1. `node scripts/set-version.mjs 0.7.11`, commit, push.
2. iOS: run the TestFlight workflow on main (first Swift compile of `NotifyFeed.swift` change).
3. Android: `npm run release:android -- 0.7.11` on the human's machine.
4. Desktop: build with `TAURI_SIGNING_PRIVATE_KEY`, upload to GitHub Release v0.7.11, then update
   `app_versions` 0.7.11 `exe_url` and `public/version.json` `exeUrl`.
5. After 0.7.11 reaches the iPhone testers: deploy push-dispatch (`test` as alert push). Before
   that, a 0.7.10 iPhone app would show the self-test twice.
6. Device checks: desktop toast click focuses the window; self-test tools visible and working on
   iOS and Android apps; iOS Focus hint shown in the permission center; D2 "limited" row.
